# 私有化部署指南

## 硬件与网络要求

私有化部署支持 Docker Compose 与 Kubernetes 两种方式。最低配置为 4 核 CPU、8GB 内存、50GB 磁盘，仅适用于 200 人以下、日活较低的试点环境。

| 环境 | CPU | 内存 | 磁盘 | 说明 |
| --- | --- | --- | --- | --- |
| 最低配置 | 4 核 | 8GB | 50GB | 试用与 POC |
| 推荐生产 | 8 核 | 16GB | 500GB SSD | 200–2000 人 |
| 高可用 | 3 节点 × 8 核 | 3 × 16GB | 3 × 1TB | 需 K8s 集群 |

服务器须开放 8080（HTTP）、8443（HTTPS）与 22（运维跳板）端口，其余端口默认关闭。建议部署在独立 VLAN，与客户办公网通过防火墙策略隔离。

## 组件架构

系统由 web 应用、API 网关、MySQL 8.0、Redis 7 四个核心组件组成，可选组件包括对象存储（MinIO）与 Elasticsearch（用于知识库全文检索）。

- MySQL 建议一主一从，开启 binlog，用于备份与只读查询；
- Redis 用于会话、分布式锁与限流计数，建议开启 AOF 持久化；
- web 与 API 网关支持多副本部署，通过 Nginx 或 SLB 做负载均衡；
- 所有组件通过内网通信，TLS 在网关层终止。

## Docker Compose 部署步骤

1. 准备服务器并安装 Docker 24 及以上、Docker Compose v2；
2. 拉取部署仓库 `kcxoa-deploy`，切换到对应版本分支；
3. 复制 `.env.example` 为 `.env`，填写数据库连接串、Redis 地址、管理员初始密码与许可证；
4. 执行 `docker compose up -d` 启动全部服务；
5. 首次启动自动初始化数据库并创建管理员账号，约需 3–5 分钟；
6. 访问 `https://<host>:8443` 进入初始化向导。

初始化向导需要完成三件事：创建管理员账号、配置企业基本信息、导入初始组织架构。管理员账号须满足密码策略（12 位、三类字符），并强制绑定 MFA。

## Kubernetes 部署要点

使用 Helm Chart 部署，Chart 版本与产品版本保持一致。关键配置项包括副本数（默认 web 2、API 2）、资源限制（request 1 核 2GB，limit 2 核 4GB）、持久化存储类（StorageClass）。

数据库建议使用云托管 RDS 或独立部署，不推荐以 StatefulSet 方式运行 MySQL。升级时使用 Helm 的滚动更新策略，maxUnavailable 设为 0。

## 日志与监控

日志集中写入 `/var/log/kcxoa` 目录，按天滚动，默认保留 30 天。日志级别可在配置文件中调整为 INFO、WARN 或 DEBUG，DEBUG 级别仅用于临时排查，排查完成后须恢复。

监控面板提供请求量、错误率、P95 响应耗时、数据库连接数、Redis 命中率等指标。告警阈值默认：错误率 > 5% 持续 5 分钟、P95 > 2000ms 持续 10 分钟、磁盘使用率 > 85%。

## 备份与恢复

采用每日全量加每小时增量的备份策略，备份文件保留 30 天，异地保留一份。备份内容包括数据库、附件存储与配置文件。

每季度执行一次恢复演练，在独立环境恢复最近一次全量备份，校验数据行数与附件可用性。升级版本前必须做一次全量备份，并记录备份文件的校验值。

## 升级流程

1. 阅读发布说明，确认是否有不兼容变更；
2. 在预发布环境完成升级演练与核心功能回归；
3. 备份数据库与附件，记录校验值；
4. 执行数据库迁移脚本，观察执行日志；
5. 切换镜像版本，滚动重启，单节点重启约 40 秒；
6. 验证健康检查接口 `/healthz` 返回 200，抽查 3 个核心流程。

升级窗口建议安排在周二或周四 22:00–24:00，与常规发布窗口保持一致。

## 常见问题排查

| 现象 | 可能原因 | 排查方式 |
| --- | --- | --- |
| 服务无法启动 | 数据库连接串错误、端口占用 | 查看容器日志与 8080 端口占用 |
| 登录报错 | Redis 不可达、会话密钥不一致 | `redis-cli ping`，检查多副本密钥配置 |
| 附件上传失败 | 磁盘空间不足、对象存储配置错误 | `df -h`，检查 MinIO 地址与桶权限 |
| 页面 502 | 网关到 web 服务不通 | 检查容器网络与服务注册 |
| 迁移脚本失败 | 数据库版本不兼容、权限不足 | 查看迁移日志，回退到备份 |

自行排查超过 30 分钟仍未定位的，提交工单并附上日志片段与部署拓扑，二线技术支持在 2 小时内响应。

## 安全加固清单

- 修改默认管理员口令，启用 MFA；
- 关闭不必要的外网端口，仅保留 8443；
- 配置访问控制列表，限制管理后台仅内网或 VPN 访问；
- 高危系统补丁在 7 天内完成安装；
- 关闭调试模式与 Swagger 公网暴露；
- 每季度核对一次账号与权限。

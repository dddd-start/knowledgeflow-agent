# 云策 OA 平台简介

## 产品定位

云策 OA 是云策科技面向中小企业的一体化办公平台，覆盖考勤、审批、报销、项目协作、知识库与数据看板六大场景。平台采用 B/S 架构，员工通过浏览器即可访问，无需安装客户端；移动端提供 H5 与微信小程序入口。

截至 2026 年 9 月，云策 OA 已服务 1200 余家企业客户，单租户最大用户数约 8000 人。

## 核心模块

| 模块 | 主要能力 | 典型使用者 |
| --- | --- | --- |
| 组织架构 | 部门树、岗位、汇报关系、人员异动 | HR |
| 考勤管理 | 打卡、补卡、排班、加班、月度汇总 | HR、全员 |
| 审批流程 | 自定义表单、多级审批、条件分支、会签/或签 | 全员 |
| 财务报销 | 报销单、发票核验、审批链路、打款批次 | 财务、全员 |
| 项目协作 | 看板、任务、里程碑、甘特图、周报 | 项目经理 |
| 知识库 | 文档管理、全文检索、问答机器人 | 全员 |

## 审批流程能力

管理员可以拖拽配置表单字段，支持的控件包括输入框、下拉框、日期选择、金额、附件上传与人员选择。审批链支持多级审批、条件分支、会签与或签模式。

系统支持金额阈值自动加签：例如报销单金额超过 10000 元时，自动插入分管 VP 审批节点；超过 50000 元时追加 CFO 节点。阈值由管理员在后台配置，与客户实际制度对齐。

审批超时提醒可配置，默认在第 3 个工作日提醒本人，第 5 个工作日升级到上级。所有审批操作留痕，支持导出审批日志用于审计。

## 知识库与智能问答

知识库模块支持 Markdown、Word、PDF 导入，自动分块并建立全文索引。开启智能问答后，员工用自然语言提问，系统先检索相关文档片段，再生成带引用来源的回答。

问答能力支持两种模式：快速模式只做一次检索与生成，响应时间通常 1–2 秒；深度模式会做问题改写与多轮检索，适合跨文档的复杂问题。管理员可以配置拒答策略，当检索不到足够证据时明确回复「知识库中暂无相关内容」。

## 版本与部署形态

云策 OA 提供标准版与企业版两个版本，均按年订阅：

- 标准版：面向 50 人以下团队，SaaS 多租户部署，开箱即用，含基础审批与考勤；
- 企业版：支持单点登录（SSO）、组织架构同步、数据备份、私有化部署与开放 API，适合 200 人以上或对数据安全要求较高的企业。

企业版支持 Docker Compose 与 Kubernetes 两种私有化部署方式，详见《私有化部署指南》。标准版单租户 API 限流 60 次/分钟，企业版为 600 次/分钟。

## 数据安全

平台采用 TLS 1.2 以上加密传输，存储层支持透明加密。权限模型为「角色 + 数据范围」双层控制，管理员可限定部门只能查看本部门数据。

系统记录全部登录与操作日志，日志保留 180 天；敏感操作（导出、删除、权限变更）二次确认并留痕。企业版支持数据分级标签，L3 及以上数据导出需审批。

## 集成与扩展

云策 OA 提供开放 API 与 Webhook：

- OpenAPI 覆盖组织、审批、考勤、报销四类数据；
- Webhook 支持审批状态变更、员工入离职事件推送；
- 内置连接器支持企业微信、钉钉、飞书的消息推送；
- 支持通过低代码表单扩展业务场景，无需改动主程序。

## 服务与支持

标准版提供工作日 9:00–21:00 在线客服，首次响应不超过 30 秒；企业版提供 7×24 工单支持，P1 故障 15 分钟内响应。详细服务标准见《客服支持与工单规范》。
